7. Auto-label the remaining images
Use a Python auto-label script that:
- loads best.pt;
- finds every .jpg / .png image recursively;
- skips images that already have your manual .xml;
- predicts grape bunch boxes;
- writes a new .xml file beside every remaining image;
- uses a confidence threshold around 0.50.
It must save Pascal VOC XML, not YOLO .txt, because your original labels are XML. Do not mix XML and TXT inside Dataset 1, Dataset 2, etc.

- dense/overlapping bunches;
- strong shadows;
